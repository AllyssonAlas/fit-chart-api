# Create Exercises Chart Usecase

> ## Case of success
1. Check if **USER** does have permission
2. Validate received **EXERCISES_CHART** data
3. Store data in database

> ## Exception - Missing data
3. Return missing data error

> ## Exception - Invalid data
3. Return invalid data error


> ## Exception - User does not exist
2. Return authorized error

> ## Exception - User does not have permission
2. Return forbidden error
